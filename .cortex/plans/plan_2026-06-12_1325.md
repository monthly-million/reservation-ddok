## 예약뚝 (Reservation-Ddok) 구현 플랜

### 기술 스택
- **Frontend**: Next.js 14 (App Router) + TypeScript + Tailwind CSS
- **Backend/DB**: Supabase (PostgreSQL + Auth + Storage + Realtime)
- **푸시알림**: Web Push API (service worker)
- **배포**: Vercel (무료 tier로 시작)
- **광고**: Google AdSense (추후 연동)
- **PWA**: next-pwa로 홈화면 추가 + 오프라인 지원

### 왜 이 스택?
- **Supabase**: 무료 tier 넉넉 (50k MAU, 500MB DB, 1GB storage), 폰 인증(SMS OTP) 내장
- **Next.js on Vercel**: 무료 배포, SSR로 SEO 좋음 (랜딩페이지에 유리)
- **PWA**: 앱스토어 없이 푸시알림 가능

### SMS 인증 비용 참고
- Supabase Phone Auth는 Twilio 연동 (건당 ~50-70원)
- 월 100명 가입 가정 시 월 5,000~7,000원
- 대안: 카카오 로그인 (무료) → 추후 전환 가능

### 구현 단계

#### Step 1: 프로젝트 초기화
- Next.js + TypeScript + Tailwind 프로젝트 생성
- Supabase 프로젝트 연동 설정
- PWA 설정 (manifest.json, service worker)
- GitHub 레포 생성 및 연결

#### Step 2: DB 스키마 설계 & 생성
```
- shops (가게 정보): id, owner_id, name, phone, location, hours, message, menu_images[]
- questions (사전예약질문): id, shop_id, type(text/radio/image), title, options[], order, required
- reservations (예약): id, shop_id, customer_name, customer_phone, answers[], status, created_at
- push_subscriptions (푸시 구독): id, shop_id, endpoint, keys
```

#### Step 3: 랜딩페이지 (/)
- 히어로 섹션: 핵심 가치 전달 ("30초만에 예약링크 생성")
- 사용법 3단계 설명
- 무료 강조 + CTA 버튼
- 모바일 퍼스트 반응형 디자인

#### Step 4: 사장님 회원가입/로그인 (/auth)
- 휴대폰 번호 입력 → SMS OTP 인증
- Supabase Phone Auth 사용

#### Step 5: 사장님 페이지 - 예약 생성 (/dashboard/create)
- 기본정보 입력 폼 (가게명, 전화번호, 위치, 영업시간, 메뉴판 사진, 전달내용)
- 사전예약질문 빌더 (구글폼 스타일)
  - 고객이름/전화번호 필수 고정 (삭제/수정 불가)
  - 주관식/객관식/이미지첨부 타입 선택
  - 드래그앤드롭 순서 변경
  - 추가/삭제 버튼
- "링크 생성" 버튼 → 고유 링크 발급

#### Step 6: 고객 예약 페이지 (/r/[shopId])
- 상단: 가게 기본정보 (이름, 위치, 영업시간, 전화번호)
- 메뉴판 사진 가로 스와이프 캐러셀 (컴팩트)
- 사장님 전달내용
- 예약 폼: 이름(필수) + 전화번호(필수) + 사장님이 만든 질문들
- "예약하기" 버튼 → 예약 완료 페이지

#### Step 7: 사장님 페이지 - 예약관리 (/dashboard/reservations)
- 예약 리스트 (최신순)
- 각 예약 카드: 고객명, 전화번호, 예약일시, 답변 내용
- 상태 표시 (신규/확인됨)
- 상호작용 없음 (취소 등 불가)

#### Step 8: 푸시알림
- Service Worker 등록
- 사장님 알림 구독 설정
- 새 예약 시 Supabase Edge Function → Web Push 발송

#### Step 9: PWA & 마무리
- manifest.json (앱 이름, 아이콘, 테마색)
- 오프라인 fallback 페이지
- "홈 화면에 추가" 안내 배너
- Google AdSense 자리 확보 (placeholder)

#### Step 10: GitHub & 배포
- GitHub 레포 생성 (`reservation-ddok`)
- Vercel 연동 설정
- README.md 작성

### 주요 페이지 구조
```
/ → 랜딩페이지
/auth → 로그인/회원가입
/dashboard → 사장님 대시보드
/dashboard/create → 예약링크 생성
/dashboard/reservations → 예약 관리
/r/[shopId] → 고객 예약 페이지
/r/[shopId]/complete → 예약 완료
```
