### 수동 작업 (너가 해야 할 것)

1. vercel.com 접속 → GitHub으로 로그인 (dq-hustlecoding 계정)
2. "Add New Project" → Import `monthly-million/reservation-ddok`
3. Framework Preset: **Next.js** (자동 감지됨)
4. Environment Variables 추가:
   - `NEXT_PUBLIC_SUPABASE_URL` = `https://gdxvmwqmcfmhtsjhrfzy.supabase.co`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = (이미 알고 있는 anon key)
5. Deploy 클릭
