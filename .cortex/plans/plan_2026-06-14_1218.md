## 예약 시스템 날짜/시간/캘린더 기능 추가

### Context

현재 `shops` 테이블에 `hours` (text) 하나만 있고, `reservations`에는 날짜/시간 컬럼이 없음. 예약은 단순히 이름+전화번호+질문만 수집하는 "문의폼" 수준.

필요한 기능:
1. **사장님이 운영 스케줄 설정** — 요일별 운영시간, 예약 간격(30분/1시간 등), 동시 예약 수
2. **고객이 날짜+시간 선택** — 캘린더에서 날짜 선택 → 가능한 시간대 표시
3. **사장님이 캘린더로 예약 확인** — 날짜별 예약 목록 조회

### DB 변경 (Migration 004)

**새 테이블: `shop_schedules`**
```sql
shop_id UUID FK → shops
day_of_week INT (0=일, 1=월, ..., 6=토)
open_time TIME  (예: 09:00)
close_time TIME (예: 18:00)
is_closed BOOLEAN DEFAULT false
```

**`shops` 테이블에 컬럼 추가:**
```sql
slot_duration_min INT DEFAULT 60  -- 예약 간격 (분)
max_per_slot INT DEFAULT 1        -- 동시 예약 수
advance_days INT DEFAULT 14       -- 몇 일 앞까지 예약 가능
```

**`reservations` 테이블에 컬럼 추가:**
```sql
reserved_date DATE
reserved_time TIME
```

**새 테이블: `shop_closures`** (임시 휴무일)
```sql
shop_id UUID FK → shops
closed_date DATE
reason TEXT
```

### 프론트엔드 변경

#### 1. 사장님 — 링크 생성/수정 시 스케줄 설정
- 요일별 운영시간 토글 (on/off + 시작/종료 시간)
- 예약 간격 선택 (30분/1시간/2시간)
- 동시 예약 수 설정
- 며칠 앞까지 예약 가능한지

#### 2. 고객 — 예약 폼에 캘린더 추가
- 날짜 선택 (달력 UI) — 오늘 이후 ~ advance_days까지
- 선택한 날짜의 가용 타임슬롯 표시
- 이미 찬 슬롯은 비활성화
- 선택 후 기존 이름/전화번호/질문 입력

#### 3. 사장님 — 예약 관리 캘린더 뷰
- 날짜별 그리드 뷰 (일간/주간)
- 예약 현황 한눈에 확인
